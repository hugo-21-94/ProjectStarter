📚 Documentation

Tout ce qu'il faut savoir pour utiliser ProjectStarter.

🚀 Générer un projet

  1. Choisissez un nom de projet.
  2. Sélectionnez HTML ou Flask.
  3. Ajoutez vos pages.
  4. Choisissez les options souhaitées.
  5. Cliquez sur Générer.

📥 Télécharger le projet

Une fois la génération terminée, un fichier ZIP sera automatiquement téléchargé sur votre ordinateur.

📂 Décompresser le ZIP

Windows :

  • Clic droit.
  • Extraire tout…

macOS :

  • Double-cliquez simplement sur le ZIP.

💻 Ouvrir dans Visual Studio Code

  1. Ouvrir Visual Studio Code.
  2. Fichier → Ouvrir un dossier.
  3. Sélectionner le dossier du projet.

🌐 Projet HTML

  1. Ouvrez home.html.
  2. Ou utilisez l'extension Live Server.

🐍 Projet Flask 


pip install -r requirements.txt

python app.py

Ensuite ouvrez : 


http://127.0.0.1:5000

Questions fréquentes

Pourquoi mon CSS ne se charge pas ?

Vérifiez que vous ouvrez bien votre projet depuis Live Server ou Flask.

Comment ajouter une nouvelle page ?

Ajoutez simplement un nouveau fichier HTML, CSS et JavaScript dans votre projet.

Puis-je modifier les fichiers générés ?

Oui. Tous les fichiers vous appartiennent et peuvent être modifiés librement.

ProjectStarter est-il gratuit ?

Oui. La première version est entièrement gratuite.

Puis-je utiliser ces projets pour des clients ?

Oui. Les projets générés peuvent être utilisés pour vos projets personnels ou professionnels.
